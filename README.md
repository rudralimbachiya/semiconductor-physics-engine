# semiconductor-physics-engine
a semiconductor physics engine to view the concept as a visual
https://rudralimbachiya.github.io/semiconductor-physics-engine/

An interactive educational simulator for exploring semiconductor
band structure, carrier statistics, doping, temperature, photon
excitation, and drift transport.

## Features

- 11 semiconductor materials
- Temperature-dependent band gaps
- Fermi–Dirac carrier statistics
- Charge-neutrality solver
- Simplified dopant ionization
- N-type / P-type / intrinsic material
- Electron and hole drift
- Photon excitation and recombination
- Interactive band diagrams
- Fermi-level visualization

## Model

The simulator is an educational bulk-semiconductor model.
It is not intended to replace TCAD or experimentally calibrated
device simulation.

## Run

Open `index.html` in a modern browser.

No installation or dependencies required.
